# 客户图片语义策展计划

- 3 张 Banner：全部作为 Hero 轮播；保持工业蓝背景和产品主体，网页 DOM 叠加真实英文文案，桌面/390px 分别定义安全区。
- 2 个 Logo：横版用于页头/页脚，方形 R 标用于 favicon；保持原色与比例。
- 7 张企业/工厂图片：按厂区外观、加工车间、自动化设备、仓储/成品区分组；不从照片推断设备品牌、产能或所有权之外事实。
- 82 张产品视觉（43 个 Excel 内嵌，其中 39 张单品/4 张组合；39 张独立正式图）：按六个产品图库主辅编排；独立“产品（修改）”目录为正式上线主来源，Excel 图片保留来源映射与组合图用途。
- 营业执照：仅核验主体，不公开。
- 公开标题、caption、alt 按产品/场景重写，不泄漏原始数字文件名或 Excel 锚点。
